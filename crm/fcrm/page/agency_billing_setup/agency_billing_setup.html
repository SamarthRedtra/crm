Agency billing — setup checklist

Operators configure global billing and Stripe here; agency admins finish onboarding in the CRM portal.

Quick links

  • Agency Billing Settings (currency, due days, Stripe keys)
  • Agent Level (daily rates)
  • Billing Addon (catalog)
  • Agency · Agent (team & billable flags)

1. Billing settings (Desk)

  1. Open Agency Billing Settings.
  2. Set default currency and invoice due days.
  3. Add Stripe publishable key, secret key, and webhook signing secret.
  4. Choose collection method: send_invoice (hosted invoices) or charge_automatically (saved card).

2. Stripe webhook

  1. Endpoint path: /api/method/crm.api.redtra.billing.stripe_webhook (full URL on your site).
  2. Events: checkout.session.completed, invoice.paid, invoice.payment_failed (include invoice.payment_succeeded if your Stripe version sends it).

3. Scheduler (bench)

Ensure Redis and the scheduler are running, and register:

  • crm.api.redtra.billing.run_daily_agency_billing (daily)
  • crm.api.redtra.billing.close_previous_month_agency_billing (monthly)

4. Master data

  1. Create Agent Level rows with daily rates.
  2. Create Billing Addon rows (daily, monthly, or usage-based).
  3. Link each billable Agent to an agent level; set Agency Role (Admin = billing, Manager = team).

5. Agency admins (portal)

  1. Agency admin opens /crm/agency-onboarding on your site.
  2. Complete profile and billing contact details; optional Stripe payment-method setup.
  3. After onboarding, use Agency Profile and Agency Billing in CRM settings.

Install the Stripe Python package on the bench if invoice sync fails. See apps/crm/AGENCY_BILLING_SETUP.md in the app repo for the same steps.
