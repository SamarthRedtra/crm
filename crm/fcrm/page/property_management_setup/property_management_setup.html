Property Management — step-by-step setup

Follow these steps once per site (or when onboarding a new team). Use the links to open each list in Desk.

  1. Areas — Define cities, communities, or zones used to classify listings.
    Open Areas
  2. Developers — Add property developers or master developers you reference on listings.
    Open Developers
  3. Amenities — Maintain amenity tags (pool, gym, etc.) available when editing properties.
    Open Amenities
  4. Agencies — Create agencies and billing profile fields as needed for your process.
    Open Agencies
  5. Agents — Create agent records, link users, set agency and verification status so they can own listings and appointments.
    Open Agents
  6. Properties — Add listings (assign agent, area, developer, status Active when ready).
    Open Properties
  7. Customers — Add customer profiles used for appointments and engagement.
    Open Customers
  8. Property appointments — After the above is in place, schedule and track viewings from Desk or the mobile app.
    Open Property Appointments

Tip: the Property Management workspace groups these DocTypes for daily work after setup is complete.
